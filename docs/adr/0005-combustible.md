# ADR-0005 — Combustible con reserva, precio fechado y acceso vial

Fecha: 2026-09-29. Estado: adoptada para diseño.

Contexto: precios históricos, estaciones cercanas inaccesibles y tanque parcialmente lleno producen recomendaciones engañosas.

Decisión: precio opcional/manual, consumo separado de compras, inicio/reserva por viaje, productos y unidades explícitos. Estaciones candidatas MUST; recomendación completa sólo con plan factible y acceso verificado.

Alternativas rechazadas: asumir tanque lleno; ordenar sólo por precio; convertir GNC a litros; suponer vigencia del antiguo régimen 314/2016.

Consecuencias: puede no haber costo o plan completo; se explica. Modelo de automóvil nafta/diésel inicial. Fuente de precios actual aún pendiente.

Revisar cuando exista inventario auditado y precio licenciado sostenido. Cálculos/casos en TRIP-ANALYSIS.md.

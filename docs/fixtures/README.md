# Fixtures

Los archivos de este directorio pertenecen al corpus de diseño original. Son datos sintéticos; no representan alertas ni cortes reales.

Las pruebas ejecutables actuales construyen casos explícitos en `tests/RutaSmart.Tests` y `mobile/rutasmart/test`. No se considera aprobado un caso del corpus por el solo hecho de estar almacenado aquí. Ver [pruebas](../../TESTING.md).
